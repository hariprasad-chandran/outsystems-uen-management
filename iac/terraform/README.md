# UEN Management System (data.gov.sg Integration)

A full-stack OutSystems web application that integrates and manages Singapore Unique Entity Number (UEN) data from data.gov.sg.

## Live Application Access
- **Application URL:** https://personal-cff72w6z.outsystemscloud.com/UENManagement/uenlist
- **Environment:** OutSystems Cloud Personal Environment

## Features
- Real-time search and filtering for UEN records.
- Integration with publicly available data from data.gov.sg.
- Responsive web UI built on OutSystems UI framework.

## Project Structure
- `UENManagement.oml`: Exported OutSystems application module.
- `iac/`: Infrastructure as Code (AWS architecture for OutSystems Platform).
- `tests/`: Automated test suite.
